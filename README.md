# AlgVis

AlgVis is an interactive algorithm visualizer built with React. It provides visual representations of various algorithms and data structures to help users better understand how they work step-by-step.

## Features

- Sorting Algorithms
- Tree Data Structures
- Graph Algorithms
- Pathfinding Algorithms
- Linked Lists

## Technologies Used

- React (with React Router)
- Vite
- JavaScript

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation

1. Navigate to the project directory:
   ```bash
   cd AlgVis
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Development Server

Start the application locally using Vite:

```bash
npm run dev
```

Open the provided local URL in your browser to view the application.
